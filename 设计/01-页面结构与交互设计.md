# 早八签到 · 页面结构与交互设计（V1.0）

> 本文档为开发前置设计，覆盖信息架构、逐页结构、核心交互、流程与边界状态。
> 数据库与 API 设计见后续文档。技术栈：Vue3 + Vant + Express + SQLite + mkcert HTTPS。

---

## 0. 与原始 PRD 的差异确认（已与你对齐）

| 项 | PRD 原述 | 本版决定 |
|---|---|---|
| 迟到 | 截止后签到=迟到 | **取消**。截止即锁死签到，逾期只能补签 |
| 定位 | 先不做 | **新增定位签到**（教师选中心点+半径，学生 GPS 范围内签到） |
| 截止提醒 | 无 | 任务卡倒计时 + 剩余 ≤15 分钟醒目提示 |
| 补签窗口 | 无限制 | 任务结束后 **24 小时内** |
| 请假与签到 | 未说明冲突 | 请假审批中 → 该课签到禁用；通过后显示"请假" |
| 出勤率分母 | 未明确 | `出勤率 = (正常+补签通过) / (应签到 − 请假)`，请假单列 |

## 1. 信息架构与导航

底部 Tab 栏按角色区分，共 4 个 Tab：

**学生端**

```
┌─────────────┬─────────────┬─────────────┬─────────────┐
│   首页      │   课程      │  我的申请    │   我的      │
│ (进行中签到) │ (加入/列表)  │ (补签+请假)  │ (个人中心)  │
└─────────────┴─────────────┴─────────────┴─────────────┘
```

**教师端**

```
┌─────────────┬─────────────┬─────────────┬─────────────┐
│   首页      │   课程      │   审批      │   我的      │
│ (快捷发起)   │ (我教的课)   │ (待办+已办)  │ (个人中心)  │
└─────────────┴─────────────┴─────────────┴─────────────┘
```

- 「审批」Tab 右上角显示待办数量徽标（补签待审 + 请假待审总数），实时刷新。
- 所有二级页面从 Tab 页 push 进入，左上角返回。

## 2. 全局设计规范

### 2.1 状态色语义（全局统一）

| 状态 | 颜色 | 说明 |
|---|---|---|
| 正常 | 绿色 `#07c160` | 按时签到 |
| 请假 | 蓝色 `#1989fa` | 请假通过，豁免 |
| 补签待审 / 请假待审 | 橙色 `#ff976a` | 审批中 |
| 缺勤 / 补签拒绝 / 请假拒绝 | 红色 `#ee0a24` | 异常 |
| 补签通过 | 青色 `#00c8c8` | 已补救 |

### 2.2 通用交互

- **加载**：列表首次加载用骨架屏（Vant Skeleton）；下拉刷新支持所有列表页；操作按钮提交中禁用防重复。
- **空状态**：统一插画 + 一句话引导 + 主按钮（如"去加入课程"）。
- **错误**：接口失败 Toast 提示 + 重试按钮；网络异常时首页任务卡显示"加载失败，点击重试"。
- **防重复**：签到、提交申请等写操作按钮在请求进行中置灰并显示 loading。
- **截止时间倒计时**：所有任务卡/任务页显示 `mm:ss` 倒计时，每秒刷新；≤15 分钟变橙并出现"即将截止"标签；截止瞬间页面自动刷新状态。

## 3. 逐页设计

### 3.1 登录 / 注册页（无 Tab）

**结构**：
- 顶部：App Logo + "早八签到"标题
- 中部：账号（学号/工号）、密码输入框
- 下方：登录按钮；底部"没有账号？注册"
- 注册：账号、姓名、密码、确认密码、**角色单选（学生/教师）**

**交互**：
- 登录成功按角色跳转对应 Tab 首页。
- 注册时学号/工号查重，重复 Toast 提示。
- 表单校验：非空、密码 ≥6 位、两次密码一致。

---

### 3.2 学生端 · 首页（Tab 1）

**结构**：
1. 顶部栏：问候语（"早上好，张三"）+ 日期
2. **进行中签到区**（核心，置顶）：
   - 任务卡：课程名、教师、签到类型图标（🔢 码 / 📍 定位）、大字号倒计时、状态按钮
   - 倒计时 ≤15 分钟：卡片描边变橙 + "即将截止"角标（可选伴随一次震动/提示音）
3. 今日课程区：今日有任务的课程速览（次要）
4. 最近缺勤提醒：有 24h 内可补签的缺勤时，置顶提示条"你有 N 条缺勤可补签 →"

**任务卡按钮状态机**：

| 场景 | 按钮 |
|---|---|
| 进行中·未签到 | 绿色「立即签到」 |
| 进行中·签到成功 | 灰色「已签到 ✓」，卡片变淡 |
| 进行中·请假审批中 | 禁用「请假审批中」 |
| 已结束·未签到·24h 内 | 橙色「申请补签」 |
| 已结束·未签到·超 24h | 灰色「缺勤」 |
| 已结束·补签待审 | 橙色「补签待审」 |
| 已结束·补签通过 | 青色「补签通过」 |
| 已结束·请假 | 蓝色「请假」 |

---

### 3.3 学生端 · 签到页（从任务卡进入）

**A. 签到码模式**

- 大字号 6 格验证码输入框（每格一个数字，自动跳格，支持粘贴）。
- 提交 → 成功：全屏成功页（✓ 动画 + "签到成功" + 时间），1.5s 后自动返回首页。
- 失败：码错误 / 已签到过 / 已截止 / 课程不匹配，Toast 具体原因，清空输入框聚焦重输。

**B. 定位模式**

- 进入即请求定位授权；顶部说明条"需要获取你的位置以完成签到"。
- 已授权：显示当前坐标、定位精度（±Xm）、与签到点的直线距离（实时刷新）。
  - 距离 ≤ 半径：绿色大按钮「签到」，点击即签。
  - 距离 > 半径：按钮禁用，显示"距签到点约 XXX 米，请在范围内签到"。
- 未授权/定位失败：提示引导去系统设置开启；提供"使用签到码"兜底入口（仅当该任务同时支持时——本期不支持，纯提示）。
- 定位精度 > 50m 时提示"定位精度较低，请稍候或移动到开阔处"。

> 地图/选点技术方案：前端用 Leaflet + OpenStreetMap（无需申请地图 Key，坐标同为 WGS-84，与浏览器 GPS 一致，无偏移误差）。

### 3.4 学生端 · 课程页（Tab 2）

- **未加入任何课程**：空状态 + 「输入邀请码加入课程」按钮。
- **加入弹窗**：6 位邀请码输入 → 成功 Toast + 刷新列表；码无效/已加入有明确提示。
- **课程列表**：课程卡 = 课程名、教师、我的出勤率环形小图（正常+补签通过口径）、最近一次任务状态。
- **课程详情**（点课程卡进入）：
  - 头部：课程信息 + 我的出勤率（大字）+ 请假/缺勤/补签次数
  - Tab ① 签到任务：历史任务列表，每条显示时间、我的状态标签（§2.1 色语义）
  - Tab ② 我的记录：同数据按时间轴展示（与①择一即可，开发取①）
  - 右上角「申请请假」按钮

---

### 3.5 学生端 · 请假申请页

**结构**：课程选择器（默认从哪个课程进来就预选哪个）→ 开始时间 → 结束时间（Vant DatetimePicker，精确到分钟）→ 请假类型（病假/事假/其他，标签选择器）→ 理由（多行文本，≥10 字）→ 提交。

**交互**：
- 时间范围合法性校验：开始 < 结束；不允许选过去已结束的任务时间段（至少覆盖一个未结束/未来的任务，否则提示"该时间段内没有可请假的课程任务"）。
- 时间段内若存在"已正常签到"的任务 → 提示"你已签到的任务不受影响"。
- 提交成功 → 跳"我的申请"页并定位到请假 Tab。

---

### 3.6 学生端 · 补签申请页

- 入口：首页缺勤提示条 / 课程详情任务列表 / 我的申请页。
- 展示上下文：课程、任务时间、缺勤状态、"剩余补签时间 Xh Xm"倒计时。
- 只需填写补签理由（≥10 字）→ 提交。
- 提交成功 → 任务状态变「补签待审」，入口按钮同步更新。

---

### 3.7 学生端 · 我的申请（Tab 3）

- 顶部 Tab：**补签申请 | 请假申请**
- 每条申请卡：类型、课程、任务时间（补签）/ 时间段（请假）、理由摘要、状态标签、教师审批意见（有则显示）。
- 状态与 §2.1 色语义一致；被可查看但不可修改/撤销（MVP 不做撤销）。

---

### 3.8 教师端 · 首页（Tab 1）

1. 顶部：问候 + 「发起签到」主按钮（醒目，最大操作入口）
2. 进行中签到区：正在进行的任务卡（课程、类型、倒计时、已签 X/Y 人、查看名单入口）；无则显示"今天还没有进行中的签到"。
3. 我的课程速览：横向滑动课程条。

---

### 3.9 教师端 · 发起签到页

**步骤式表单（单页分组）**：

1. **选择课程**：课程选择器（无课程则引导先去创建）
2. **签到方式**：单选卡片二选一 —— 「🔢 签到码」「📍 定位签到」
3. **定位签到附加项**：
   - 地图选点：Leaflet 地图，可拖动 Marker 或点地图取点；顶部搜索框（OSM Nominatim 地理编码）选点后地图飞至该点
   - 半径选择：100 / 300 / 500 米胶囊选择器（默认 300）
   - 显示"已选中心点：XX.XXXX, XX.XXXX"
4. **签到时长**：胶囊快捷选项（5 / 10 / 15 / 30 / 45 分钟）+ 自定义截止时间（默认从当前时间起 10 分钟）
5. **创建**：
   - 码签到 → 成功页展示 6 位签到码（大字号、可复制）+ 已签进度入口
   - 定位签到 → 成功页提示"学生需在该位置范围内签到"

**规则**：同一课程同时只能有一个进行中任务；发起前若存在进行中任务，提示"已有进行中的签到，请先结束"。

---

### 3.10 教师端 · 进行中签到管理页（任务详情）

- 顶部状态条：进行中（绿）/ 已结束（灰）、倒计时、签到方式、（码签到显示签到码，可复制）
- 实时进度：环形进度图 `已签 X / 应签 Y`，每 5 秒自动刷新
- 名单 Tab：**已签到 | 未签到 | 请假 | 补签**
  - 未签到 Tab 实时显示"谁还没签"（早八点名核心场景）
- 「提前结束」按钮：二次确认后结束任务，未签者即刻记缺勤（可补签窗口从此时起算）

---

### 3.11 教师端 · 审批中心（Tab 3）

- 顶部 Tab：**待审批 | 已审批**
- 待审批列表卡：申请类型（补签/请假标签）、学生姓名+学号、课程、理由摘要、申请时间；整卡点击进入审批详情。
- 已审批列表卡：同上 + 审批结果 + 意见。
- 审批详情页：
  - 完整信息（学生、课程、任务/时间段、理由全文、申请时间）
  - 「通过」「拒绝」大按钮 + 审批意见输入框（选填）
  - 操作后 Toast + 返回列表自动刷新，Tab 徽标数 -1
- 空状态："没有待审批的申请 🎉"

### 3.12 教师端 · 统计页

**入口**：课程详情 → 某次任务 → 统计；或课程详情 → 整体统计。

**A. 单次任务统计**
- 顶部四宫格：出勤率（大字环形图）、正常 X 人、请假 X 人、缺勤 X 人
- 下方名单 Tab：正常 / 请假 / 缺勤（缺勤含补签状态细分）/ 补签，支持按姓名搜索
- 右上角导出按钮（CSV，MVP 简版导出，可选做）

**B. 课程整体统计**
- 总应签人次、出勤率趋势（简单折线）、按学生名单列表（姓名 / 出勤率 / 正常 / 请假 / 缺勤 / 补签通过 计数）
- 点击学生行 → 该生本课程签到明细

- 教师额外显示：创建课程数、累计发起签到次数
- 「退出登录」（二次确认）

## 4. 核心流程

### 4.1 教师闭环

```
登录 → 创建课程(得邀请码) → 口头告知学生
  → 发起签到(码/定位+时长) → 实时看已签/未签名单
  → 提前或到时结束 → 看统计(出勤率/缺勤名单)
  → 审批中心处理 补签/请假 → 统计自动更新
```

### 4.2 学生闭环

```
登录 → 输邀请码加入课程
  → 首页看到进行中签到 → 倒计时提醒
  → 签到(输码 / GPS 范围内点击)
  → 若缺勤：24h 内申请补签 → 等审批 → 看结果和教师意见
  → 若预知缺勤：提前请假 → 该课签到被禁用 → 审批通过显示"请假"
```

### 4.3 请假拦截流程（关键交互）

```
学生提交请假(覆盖任务T)
  → T 任务卡按钮变「请假审批中」禁用
  → 教师通过 → T 显示「请假」(蓝色)，不计入出勤率分母
  → 教师拒绝 → 若 T 未结束：恢复「立即签到」
              若 T 已结束：显示「申请补签」(24h 窗口内)
```

## 5. 边界与异常状态清单

| # | 场景 | 表现 |
|---|---|---|
| 1 | GPS 授权被拒 | 引导去系统设置；签到页提供重试按钮 |
| 2 | GPS 精度差（>50m） | 提示等待/移动，仍显示距离但建议改善 |
| 3 | 学生在半径外 | 显示距离，按钮禁用 |
| 4 | 签到码错误/过期 | Toast 区分提示，输入框清空重聚焦 |
| 5 | 重复签到 | 服务端拦截，前端 Toast"已签到" |
| 6 | 截止时间到（学生正停留在签到页） | 页面自动变为"已截止"，引导补签入口 |
| 7 | 补签超 24h | 不显示补签入口，仅"缺勤" |
| 8 | 请假时间段内无任何任务 | 前端拦截提示 |
| 9 | 教师结束任务瞬间学生正在提交 | 服务端以服务端时间为准，返回"已截止" |
| 10 | 审批时任务数据已变化 | 以提交时快照为准，不受影响 |
| 11 | 教师重新生成邀请码 | 旧码立即失效，已加入学生不受影响 |

## 6. 非功能与部署

- **HTTPS**：mkcert 生成本地 CA + 局域网证书；Windows 双击安装到受信任根；iOS 需安装描述文件并开启完全信任（安装步骤将写入 README）。
- **局域网访问**：Express 绑定 `0.0.0.0`，启动时终端打印局域网 IP + 端口二维码（终端 ASCII 二维码，方便手机扫码直达）。
- **种子数据**：1 教师 + 10 学生 + 3 门课程 + 历史任务覆盖全部状态（含 1 个进行中任务、1 个 24h 内可补签缺勤、1 条待审请假、1 条待审批补签），登录即演示。
- **浏览器兼容**：iOS Safari / Android Chrome / 微信内置浏览器；定位能力以浏览器 Geolocation 为准。
