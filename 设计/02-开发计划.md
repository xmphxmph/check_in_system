## 0. 技术选型定案

| 层 | 选型 | 理由 |
|---|---|---|
| 前端 | Vue3 + Vite + Vant 4 + Vue Router + Pinia | PRD 指定；Vant 移动端组件齐全 |
| 后端 | Node.js + Express | PRD 指定 |
| 数据库 | SQLite（better-sqlite3，同步 API） | 零配置、本地文件、事务简单 |
| 鉴权 | JWT（jsonwebtoken）+ bcryptjs 哈希 | 无会话状态，适合移动端 Web |
| HTTPS | mkcert 本地 CA 证书 | 浏览器定位 API 强制要求安全上下文 |
| 地图 | Leaflet + OpenStreetMap（WGS-84） | 免 Key，与浏览器 GPS 坐标系一致 |
| 真机直达 | 终端打印局域网 IP + `qrcode-terminal` ASCII 二维码 | 手机扫码即开 |

## 1. 数据库设计（最终版，相对 PRD 的变更已标注）

```sql
User(id, name, role, account UNIQUE, password_hash, created_at)
Course(id, name, teacher_id → User, invite_code UNIQUE, created_at)
Enrollment(id, course_id, student_id, joined_at, UNIQUE(course_id, student_id))
SignInTask(
  id, course_id, type,              -- type: 'code' | 'location'   【新增】
  code,                             -- 6 位数字，仅 code 类型使用
  center_lat, center_lng, radius_m, -- 仅 location 类型使用        【新增】
  start_time, end_time,
  status,                           -- 'active' | 'ended'
  ended_at, created_at)
SignInRecord(
  id, task_id, student_id,
  sign_time, status,                -- normal | appeal_pending | appeal_approved |
                                    -- appeal_rejected | leave（无 late，已删）【变更】
  lat, lng,                         -- 定位签到时记录              【新增】
  UNIQUE(task_id, student_id))
Appeal(id, task_id, student_id, reason, status,        -- pending|approved|rejected
       teacher_comment, created_at, reviewed_at)
LeaveRequest(id, course_id, student_id, leave_type,    -- sick | personal | other
       start_time, end_time, reason, status,
       teacher_comment, created_at, reviewed_at)
```

**关键派生逻辑（写在 `utils/status.js`，前后端共用同一套规则）：**

- 任务 `ended`（ended_at 非空 或 当前时间 > end_time）后，无签到且无通过请假覆盖的记录 → `absent`。
- 请假通过时，把该课程、时间段内**未签到**的记录置为 `leave`；已签到的 `normal` 不覆盖。
- 出勤率（课程维度）：`(normal + appeal_approved) / (任务总数 − leave 数)`。
- 补签资格：`任务已结束 && 本人 absent && 距 ended_at < 24h && 无历史 Appeal`。
- 签到拦截顺序（服务端判定，从高优先级）：任务不存在 → 非本课程学生 → 已签到 → 任务未开始/已截止 → **有覆盖本任务的 pending/approved 请假** → 码错误/距离超半径。

## 2. API 设计（REST，统一前缀 `/api`，统一错误 `{code, message}`）

**auth**
| 方法 | 路径 | 说明 |
|---|---|---|
| POST | /auth/register | 学号/工号 + 姓名 + 密码 + 角色 |
| POST | /auth/login | 返回 JWT + 用户信息 |
| GET | /auth/me | 当前用户 |

**courses**
| 方法 | 路径 | 说明 |
|---|---|---|
| GET | /courses | 按角色返回我教的/我加入的课程（含出勤率摘要） |
| POST | /courses | 教师创建，返回 6 位邀请码 |
| POST | /courses/join | 学生输邀请码加入 |
| POST | /courses/:id/regenerate-code | 教师重置邀请码（二次确认在前端） |
| GET | /courses/:id | 课程详情 + 我的统计 |

**signin-tasks**
| 方法 | 路径 | 说明 |
|---|---|---|
| POST | /signin-tasks | 教师发起（type/code 或 type/location+坐标+半径+end_time） |
| GET | /signin-tasks/active | 学生首页：进行中任务（含我的状态、倒计时字段） |
| GET | /signin-tasks?course_id= | 课程任务列表（含我的记录状态） |
| GET | /signin-tasks/:id | 任务详情（教师含签到码/坐标，学生不含码） |
| POST | /signin-tasks/:id/sign | body: `{code}` 或 `{lat, lng}`；服务端校验时间窗/请假覆盖/码/距离 |
| POST | /signin-tasks/:id/end | 教师提前结束 |
| GET | /signin-tasks/:id/records | 教师名单（已签/未签/请假/补签四分组 + 每生状态） |

**appeals（补签）**
| 方法 | 路径 | 说明 |
|---|---|---|
| POST | /appeals | 仅 24h 窗口内的缺勤任务，幂等（同任务一次） |
| GET | /appeals/my | 学生我的申请 |
| GET | /appeals?course_id=&status= | 教师审批列表 |
| PUT | /appeals/:id/review | `{approve: bool, comment}`，事务内更新 Appeal + Record 状态 |

**leaves（请假）**
| 方法 | 路径 | 说明 |
|---|---|---|
| POST | /leaves | 校验时间段覆盖至少一个任务；创建后该时段任务签到被拦截 |
| GET | /leaves/my | 学生我的申请 |
| GET | /leaves?course_id=&status= | 教师审批列表 |
| PUT | /leaves/:id/review | 通过时事务内批量把覆盖任务未签到记录置 `leave`；拒绝时解除签到拦截 |

**stats**
| 方法 | 路径 | 说明 |
|---|---|---|
| GET | /courses/:id/stats | 课程整体：出勤率、按学生名单计数 |
| GET | /signin-tasks/:id/stats | 单次任务：出勤率、正常/请假/缺勤/补签名单（可导出 CSV，选做） |

## 4. 关键实现要点（易踩坑，提前定死）

1. **签到判定以服务端时间为准**；`end_time` 到时由首次相关请求触发惰性置 `ended`（另加一个 1 分钟轮询兜底），避免依赖定时器。
2. **请假拦截在 sign 接口内做**：查询是否存在覆盖该任务时间段的 pending/approved 请假，有则按状态拒绝（pending → "请假审批中，暂不可签到"）。
3. **审批通过/拒绝用事务**（better-sqlite3 `db.transaction`）：Approval 状态与 Record 状态/签到拦截同步变更，杜绝半提交。
4. **距离计算用 haversine**，WGS-84；Leaflet 选点与浏览器 GPS 同坐标系，无 GCJ-02 偏移问题。
5. **邀请码/签到码生成防碰撞**：随机生成后查库重试，课程邀请码 6 位字母数字、签到码 6 位数字。
6. **Vite 代理 + HTTPS**：dev 环境下前端 https，代理到 http Express 内部链路即可，无需给 Express 也套证书（生产形态再议，MVP 不部署）。
7. **OSM 瓦片访问**：国内网络下 osm.org 瓦片可能较慢，README 注明备选（切换高德瓦片需做 GCJ-02 转换，本期不做）；地图选点同时支持"直接输入经纬度"兜底。

## 5. 风险与对策

| 风险 | 影响 | 对策 |
|---|---|---|
| 手机浏览器定位被系统/浏览器策略拒绝 | 定位签到不可用 | 签到页内置授权引导与重试；验收演示前在真机设置中允许定位（README 步骤） |
| iOS 证书信任步骤繁琐 | 真机访问卡住 | README 配图步骤 + dev.ps1 输出提示；mkcert CA 只需装一次 |
| 教室室内 GPS 漂移 > 半径 | 学生无法签到 | 半径下限 100m + 精度提示；建议教师把中心点设在教学楼门口/默认 300m |
| OSM 瓦片加载失败 | 教师无法地图选点 | 支持手动输入经纬度兜底；README 注明网络要求 |
| 同 Wi-Fi 隔离（校园网 AP 隔离） | 手机访问不到电脑 | README 注明需关闭 AP 隔离或电脑开热点给手机连 |
